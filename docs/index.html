1. GitHub controlla i segreti nei log Actions

Dal 9 novembre il secret scanning può rilevare credenziali nei log dei workflow completati. È una preview Enterprise, senza analisi retroattiva né notifiche automatiche. Importante per la sicurezza CI; da verificare su progetti con pipeline sensibili.

2. Claude Fable 5.2 su GitHub Copilot

3. openSUSE Tumbleweed passa verso Agama

4. Firefox 160: dettatura locale e Mini Window

5. Slax 2026.11, Debian portatile con AI
