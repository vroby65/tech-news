2. DeepSeek DSec: milioni di sandbox al giorno per addestrare agenti

DeepSeek descrive DSec, un’infrastruttura progettata insieme al framework di reinforcement learning per separare l’esecuzione stateful degli agenti dal training GPU. Il paper parla di unità di produzione da circa 160 nodi, oltre 380.000 sandbox concorrenti e più di 5.000 creazioni di sandbox al secondo.

Perché conta: mostra quanto l’addestramento degli agenti moderni dipenda ormai dall’infrastruttura di ambienti isolati, non solo dal modello. È un tema importante per capire come stanno evolvendo coding agent e sistemi operativi agentici.

Fonte: arXiv — DeepSeek Elastic Compute

3. GitHub ha completato la migrazione da CSS-in-JS a CSS Modules

GitHub racconta una migrazione pluriennale del frontend di github.com. Il team Primer ha sostituito progressivamente CSS-in-JS con CSS Modules, usando feature flag, test di regressione visuale e codemod. GitHub riporta miglioramenti del 55% nel tempo di rendering server-side per alcune parti di Primer e del 25% nell’inizializzazione dei componenti; github.com gira al 100% su CSS Modules da giugno 2026.

Perché conta: è un caso reale molto utile per chi valuta il costo runtime di CSS-in-JS su applicazioni grandi.

Fonte: GitHub Engineering

5. Reladraw: diagrammi deterministici pensati anche per agenti

Reladraw è un progetto open source che descrive diagrammi tramite relazioni e vincoli testuali invece di affidarsi a un auto-layout imprevedibile. Il resolver produce una disposizione deterministica e il progetto punta anche a diagnostiche machine-readable, così un agente può correggere il file sorgente senza dover interpretare pixel o screenshot.

Perché conta: è un approccio molto adatto ai coding agent: sorgente testuale, output riproducibile e possibilità di validazione automatica.

Fonte: GitHub — reladraw/reladraw
