Tech News Daily — 13 novembre 2026

Novità del 12 novembre e delle prime ore del 13: sicurezza di database, driver GPU e reverse proxy, modifiche a GitHub Actions e software Linux.

1. PostgreSQL: 52 vulnerabilità corrette, fine supporto per la versione 14

Il 12 novembre sono uscite le versioni 18.7, 17.12, 16.16, 15.20, 14.25 e 19 RC2. Correggono 52 vulnerabilità e oltre 140 bug; 14.25 è l'ultima release della serie 14.

Perché conta: Aggiornare dopo backup e controllare le note di migrazione; programmare il passaggio dalla versione 14.

Fonte: https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/

2. NVIDIA: vulnerabilità NvRoot e ForgePtr nei driver Linux

Il 12 novembre sono state divulgate NvRoot (CVE-2026-47591) e ForgePtr (CVE-2026-47501), che minacciano l'isolamento delle GPU condivise e possono consentire escalation di privilegi. Le patch variano per ramo driver.

Perché conta: Priorità ai server AI multi-tenant e ai servizi cloud con GPU condivise.

Fonte: https://www.phoronix.com/news/NVIDIA-NvRoot-ForgePtr

3. Nginx Proxy Manager 2.17: correzioni di sicurezza

La nuova versione aggiunge rate limiting al login, limita meglio i permessi sui proxy e corregge difetti dei certificati, inclusa l'esposizione delle chiavi private via API.

Perché conta: Aggiornamento da valutare rapidamente per i server self-hosted esposti su Internet.

Fonte: https://linuxiac.com/nginx-proxy-manager-2-17-released-with-security-and-ssl-fixes/

4. GitHub Actions: ARM32 non più supportato sui runner ospitati dall'8 dicembre

GitHub ha annunciato il 12 novembre la fine dell'esecuzione nativa AArch32 sui runner Linux e Windows ospitati, collegata al passaggio a Node 24.

Perché conta: Controllare le pipeline per Raspberry Pi a 32 bit e considerare runner propri o cross-compilazione.

Fonte: https://github.blog/changelog/2026-11-12-actions-for-arm32-linux-windows-retirement/

5. GitHub Secret Scanning rileva token Cloudflare Access

Il changelog del 12 novembre annuncia un nuovo rilevatore di token di servizio Cloudflare nei repository.

Perché conta: Utile per individuare credenziali pubblicate accidentalmente; i token esposti vanno revocati.

Fonte: https://github.blog/changelog/month/11-2026/

6. LibreOffice 26.8.3 corregge 45 problemi

L'aggiornamento del 12 novembre risolve crash di Writer, Calc e Impress, problemi con file Office e un ciclo anomalo del Navigator.

Perché conta: Aggiornamento di manutenzione utile per desktop Linux, da installare attraverso i repository quando disponibile.

Fonte: https://linuxiac.com/libreoffice-26-8-3-released-with-45-bug-fixes-across-the-suite/
