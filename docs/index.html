1. Nginx corregge 10 vulnerabilità, alcune critiche

Le versioni 1.30.7 e 1.31.9 correggono dieci problemi, inclusi difetti HTTP/2 di corruzione della memoria e use-after-free. I rischi dipendono dai moduli e dalle configurazioni utilizzate.

Perché conta: Per chi espone reverse proxy su Internet è la priorità: controllare versione e pacchetti corretti dalla distribuzione.

2. GitHub CLI 2.105: gli agenti possono attendere eventi delle pull request

Il comando gh event listen permette di ricevere eventi in JSON su review, conflitti, controlli e modifiche delle PR, senza interrogazioni periodiche.

Perché conta: Utile per agenti di coding e automazioni GitHub; Event Streams è ancora in anteprima e richiede accesso alla waitlist.

4. ClamAV 1.5.5 corregge dieci vulnerabilità

L'aggiornamento di sicurezza affronta problemi tra cui corruzione della memoria e crash durante la scansione di contenuti preparati appositamente.

Perché conta: Da aggiornare sui server di posta e sui sistemi che analizzano file non fidati.

5. Wine prepara un passo importante verso Wayland

Nel codice destinato a Wine 11.23 è stata integrata la presentazione remota di immagini OpenGL: le applicazioni basate su Chromium Embedded Framework possono ora renderizzare con il driver Wayland nativo e WineD3D.

Perché conta: Riduce un ostacolo alla migrazione da X11, ma non è ancora una release stabile distribuita.
