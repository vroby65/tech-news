Notizie del 19 novembre 2026 e delle prime ore del 20 novembre

Le principali novità verificabili riguardano database, PHP, sicurezza APT e self-hosting. Selezione senza duplicati, con priorità alle fonti primarie.

1. PostgreSQL 19: manutenzione online e query più controllabili

La nuova versione introduce REPACK (CONCURRENTLY) per riorganizzare tabelle senza bloccare letture e scritture, pg_plan_advice per stabilizzare i piani di esecuzione e miglioramenti alle prestazioni. Conta per database in produzione; da approfondire prima di migrare, verificando estensioni e backup.

2. PHP 8.6: nuove funzioni per chi sviluppa

Rilasciata la versione stabile con applicazione parziale delle funzioni, API Io\Poll, Time\Duration e clamp(). Cambiano anche alcune impostazioni di sicurezza delle sessioni. Conta per applicazioni web e script PHP; vale testare la compatibilità prima dell'aggiornamento.

Fonte primaria o approfondimento

3. APT di Debian elimina compatibilità legacy per ridurre i rischi

Dopo una vulnerabilità nella gestione dei download, uno sviluppatore Debian ha annunciato la rimozione prevista di formati obsoleti: firme Release.gpg separate, hash deboli e repository senza metadati adeguati. Non è ancora una modifica distribuita in tutte le versioni stabili. Conta anche per chi usa Mint e Ubuntu con repository esterni: verificare le sorgenti APT.

Fonte primaria o approfondimento

4. Valkey 9.2: snapshot senza fork e meno memoria

L'alternativa libera a Redis introduce snapshot RDB senza fork (opzionali), compressione della replica e sorted set basati su B+ tree. Il progetto indica una riduzione del 36–43% dell'overhead per elemento in alcuni sorted set. Conta per servizi self-hosted e cache: vale provarlo su un ambiente di test.

Fonte primaria o approfondimento

5. GitHub: streaming dei log di audit S3 con OpenID Connect

GitHub ha esteso a GHE.com lo streaming dei log di audit verso S3 mediante OpenID Connect. Conta soprattutto per amministratori enterprise: consente integrazioni senza credenziali statiche di lunga durata. Per piccoli repository personali è una novità secondaria.
