Recap tech — 3 ottobre 2026

Le ultime 24 ore portano soprattutto novità concrete su sviluppo e open source: COSMIC vieta i contributi generati dagli LLM, GitHub rende la code review di Copilot richiamabile via API, Valve continua a rifinire il codec Pyrowave e Qualcomm mostra quanto è maturato lo stack grafico Linux open source per Snapdragon. Sul fronte dei grandi modelli AI non emerge una nuova major release ufficiale di OpenAI, Anthropic, Google DeepMind o DeepSeek nelle ultime 24 ore.

1. COSMIC vieta codice e perfino descrizioni di PR generate dagli LLM

Il progetto COSMIC di System76 ha irrigidito nettamente la propria policy: le pull request devono ora dichiarare di non contenere contenuto generato da LLM, compresi codice, commenti e descrizione della PR. Il motivo indicato dai maintainer è soprattutto pratico: i contributi AI di persone che conoscono poco il progetto stanno aumentando il carico di revisione e raramente vengono accettati.

Perché conta: è quasi l'opposto della policy adottata da altri progetti che ammettono AI purché dichiarata. Il problema emergente nell'open source non è più soltanto “il codice AI è buono?”, ma chi paga il costo della revisione. Da approfondire: sì; potrebbe diventare un precedente importante per altri grandi progetti.

Fonte: Linuxiac

2. GitHub Copilot Code Review diventa richiamabile via REST e GraphQL

GitHub permette ora di richiedere una Copilot code review direttamente tramite REST o GraphQL API, scegliendo anche il livello di effort. “Balanced” diventa il valore predefinito. Questo consente di inserire la revisione AI dentro script, pipeline CI e strumenti interni senza doverla avviare manualmente dalla pagina della pull request.

Perché conta: la code review AI diventa una primitive automatizzabile, quindi può entrare facilmente in workflow agentici e CI. Da provare: sì, soprattutto su repository dove una seconda revisione automatica può essere eseguita prima di coinvolgere una persona.

Fonte primaria: GitHub

3. GitHub Copilot ritira quattro modelli: il ricambio diventa rapidissimo

Dal 2 ottobre GitHub ha deprecato in tutti gli ambienti Copilot Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7 Code e Claude Opus 4.7. Le alternative consigliate sono rispettivamente Gemini 3.8 Flash, Kimi K3 e Claude Opus 5.5.

Perché conta: per chi costruisce workflow e agenti fissando esplicitamente il nome del modello, il ciclo di vita sta diventando molto breve. Conviene separare la configurazione del modello dal codice dell'agente e prevedere un fallback. Da fare: controllare eventuali configurazioni Copilot che nominano esplicitamente uno dei quattro modelli.

Fonte primaria: GitHub

4. Valve continua a spingere Pyrowave per Steam Remote Play

La nuova Steam Client Beta migliora il calcolo automatico del bitrate del codec Pyrowave, aggiunge parametri per regolarne la qualità e permette bitrate manuali fino a 1 Gbit/s. Valve avverte però che aumentare la banda aumenta anche la latenza: l'obiettivo rimane ottenere streaming locale ad altissima qualità e bassissimo ritardo, non semplicemente spingere più dati possibile.

Perché conta: Valve sta costruendo uno stack di streaming sempre meno dipendente dai codec video tradizionali, utile per Steam Deck, Steam Machine e Steam Frame. Da provare: sì su rete Ethernet veloce; Pyrowave resta sperimentale e richiede il client Beta.

Fonte: GamingOnLinux

5. Qualcomm: Freedreno/Turnip ormai è uno stack Linux strategico, non un esperimento

Al X.Org Developers Conference Qualcomm ha riepilogato il lavoro upstream su MSM DRM, Freedreno e Turnip. Il supporto comprende i nuovi Snapdragon X2 e Adreno 800; Rusticl è abilitato di default con OpenCL 3.1. Tra i prossimi obiettivi ci sono GPU firmware scheduling, Shared Virtual Memory per OpenCL e l'uso del nuovo matrix core MALU di Adreno 850 per carichi compute.

Perché conta: Snapdragon sta acquisendo uno stack grafico Linux upstream sempre più completo, compreso compute oltre alla grafica. Questo rafforza concretamente la possibilità di laptop ARM Linux competitivi nel 2027. Da seguire: decisamente sì, soprattutto Snapdragon X2 e MALU.

Fonte: Phoronix/XDC 2026

6. Cloudflare prepara una CA pubblica gratuita alternativa a Let's Encrypt

Cloudflare sta costruendo una Certificate Authority pubblica gratuita e ACME-first. Ha chiesto l'inclusione nei root program di Chrome, Apple, Microsoft e Mozilla e ha firmato un accordo per acquisire una root GlobalSign già ampiamente fidata. L'emissione richiederà automazione ACME con supporto ARI; per il primo trimestre 2027 sono previsti anche i Merkle Tree Certificates orientati al mondo post-quantum.

Attenzione: Cloudflare non sta ancora emettendo questi certificati pubblici: deve completare i processi di trust. Perché conta: per self-hosting e server Linux potrebbe nascere una vera seconda infrastruttura gratuita su scala Let’s Encrypt, utilizzabile cambiando sostanzialmente l'endpoint ACME. Da seguire: sì, soprattutto quando verrà aperta l'emissione pubblica.

Fonte primaria: Cloudflare

Da tenere d'occhio

Policy AI nell'open source — COSMIC sceglie il divieto mentre altri progetti accettano contributi AI dichiarati: nel 2027 potrebbe diventare una questione standard nella governance dei repository.

Copilot Code Review API — rende molto semplice costruire una pipeline “agente scrive → agente revisiona → umano approva”, con implicazioni interessanti anche sui costi e sulla qualità.

Snapdragon X2 + Turnip — driver kernel, Vulkan, OpenCL e compute stanno convergendo rapidamente verso uno stack ARM Linux completo.

Cloudflare CA — quando entrerà realmente in produzione potrebbe diventare una delle alternative più importanti a Let's Encrypt per server e servizi self-hosted.
