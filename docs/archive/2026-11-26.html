Intelligenza artificiale cinese

1. Qwen Code 1.0: nuova versione preliminare

Qwen Code 1.0.0-preview.2 introduce Qwen4-Max nel catalogo dei modelli disponibili tramite abbonamento, con contesto da un milione di token e supporto a immagini e video.

Perché conta: un'alternativa cinese a Codex e Claude Code da seguire con attenzione. La disponibilità tramite abbonamento non implica il rilascio dei pesi del modello.

Fonte: Qwen Code · AGI Hunt

2. Tencent Hy-MT3: traduzione locale in 102 lingue

Una famiglia di modelli a pesi aperti pubblicata il 24 novembre con licenza Apache 2.0, non inclusa nell'edizione precedente.

ModelloParametriMemoria teorica dei pesi a 4 bit

Le stime non includono cache, runtime e altri costi di memoria. La compatibilità con Ollama non è ancora verificata.

Perché conta: il modello più piccolo potrebbe risultare adatto a traduttori offline su computer economici.

Fonte: Tencent Hunyuan su Hugging Face · LLM Lineage

3. Magnitude: eseguire un modello da 180 miliardi di parametri con 64 GB

Un motore di inferenza open source distribuisce i pesi dei modelli fra GPU, RAM e SSD.

In una dimostrazione riportata oggi, un Qwen da 180 miliardi di parametri quantizzato a 2 bit avrebbe raggiunto 56 token al secondo su Apple M4 Max con 64 GB di memoria.

Il risultato è ancora da verificare indipendentemente.

Perché conta: potrebbe ridurre sensibilmente i requisiti hardware per i grandi modelli MoE.

Fonte: AGI Hunt

Un progetto sperimentale denominato asm-llm-os integra Qwen3-0.6B in un sistema operativo x86-64 privo di Linux, Windows e libc.

Fonte: AGI Hunt

Linux, open source e virtualizzazione

5. Proxmox VE 9.3: disponibile anche per ARM64

Pubblicata ieri la nuova versione della piattaforma open source per la virtualizzazione.

  • Debian 13.8 come base.
  • Kernel Linux 7.0 predefinito e 7.3 opzionale.
  • QEMU 11.1, LXC 7 e ZFS 2.4.
  • Gestione centralizzata dello storage SAN.
  • Snapshot LVM supportati in produzione.
  • ISO ufficiale ARM64.
  • Proxmox Offline Mirror 0.8, con sincronizzazione più efficiente.

Perché conta: interessante sia per il self-hosting sia per la realizzazione di infrastrutture completamente offline.

Fonte: Annuncio ufficiale Proxmox

6. Manjaro 27.0 Caldonia

La nuova versione include Linux 7.3, GNOME 51, Plasma 6.8 e COSMIC 1.11.

Perché conta: permette di sperimentare diverse tecnologie desktop recenti. Il repository stabile di Manjaro comprende anche Cinnamon 6.8, senza che questo costituisca un annuncio di una nuova versione di Linux Mint.

Fonti: Linuxiac · Forum ufficiale Manjaro

7. Linux 7.4 rinuncia a un'ottimizzazione LLVM

Disabilitato l'utilizzo di LLVM Profi per evitare regressioni prestazionali e tempi di compilazione eccessivi.

Perché conta: dimostra che ottimizzazioni più aggressive del compilatore non garantiscono necessariamente un kernel più veloce.

Fonte: Phoronix

8. GNU Linux-libre: firmware Wi-Fi ottenuto tramite reverse engineering

Segnalato un firmware libero per un vecchio chipset Wi-Fi 802.11 b/g.

Perché conta: interessante per il recupero di hardware datato e per le distribuzioni che intendono eliminare i componenti proprietari.

Fonte: Phoronix

GitHub Trending: progetti da approfondire

Nod

Agente personale open source eseguito sul proprio computer, progettato per interagire con applicazioni e siti web utilizzando un modello AI scelto dall'utente.

CLI-Anything

Strumento per realizzare interfacce a riga di comando utilizzabili dagli agenti.

MiniMind

Framework per addestrare piccoli modelli linguistici e studiarne il funzionamento.

T3 Code

Interfaccia per gestire agenti di programmazione locali anche da altri dispositivi.

AutoClip

Applicazione desktop open source per ricavare automaticamente brevi filmati da video più lunghi.
