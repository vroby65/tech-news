Tech News Daily — 9 novembre 2026

Novità verificate dell'8 novembre e delle prime ore del 9: file manager KDE, WSL, package manager Linux e monitoraggio self-hosted. Nessuna notizia non verificata viene presentata come release.

1. Dolphin recupera la vista a colonne dopo 15 anni

L'8 novembre KDE ha mostrato il ritorno sperimentale della navigazione a colonne (Miller columns) nel file manager Dolphin: cartelle affiancate, gerarchia sempre visibile e larghezze regolabili. Non è ancora una release stabile; gli sviluppatori chiedono test entro il 12 novembre. Perché conta: migliora la navigazione profonda nelle directory; interessante anche per chi usa file manager come Caja o Midnight Commander.

2. CachyOS arriva ufficialmente nell'ecosistema WSL

L'8 novembre è stato confermato il lavoro tra CachyOS e Microsoft per inserire la distribuzione Arch ottimizzata fra quelle supportate da Windows Subsystem for Linux. L'immagine .wsl è già installabile manualmente con WSL 2 aggiornato. Perché conta: amplia le opzioni per sviluppatori che usano Linux su Windows; non implica un vantaggio prestazionale automatico su ogni carico.

Fonte e approfondimento

3. aerynOS aggiorna Moss e prepara il kernel 7.3

L'aggiornamento dell'8 novembre del ramo unstable di aerynOS porta Linux 7.2.15, systemd 261.5 e modifiche a Moss, Boulder ed Ent per comandi e versionamento dei pacchetti Git. La serie 7.3 è attesa nel repository volatile. Perché conta: laboratorio interessante per package manager alternativi, ma non una release stabile da usare senza precauzioni.

Fonte e approfondimento

4. Zabbix 8.0 LTS: OpenTelemetry, ClickHouse e server MCP

L'8 novembre sono emersi nuovi approfondimenti su Zabbix 8.0 LTS, pubblicato ufficialmente il 5 novembre: monitoraggio applicativo con OpenTelemetry, gestione avanzata degli eventi, integrazione ClickHouse e server MCP per agenti AI. Perché conta: piattaforma self-hosted concreta per monitorare server e impianti; l'integrazione MCP richiede attenzione ai permessi. La data di release è il 5, non l'8 novembre.
