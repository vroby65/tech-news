Tech News Daily — 16 ottobre 2026

Le novità del 15 ottobre e delle prime ore del 16: AI, Linux, open source, sviluppo software e sicurezza.

In evidenza: un nuovo modello aperto di Meta, Ubuntu 26.10, Forgejo 17, GitHub che automatizza le correzioni di sicurezza e un aggiornamento importante per Steam su Linux.

1. Meta pubblica Muse Spark Open: 816 miliardi di parametri e supporto GGUF

Il 15 ottobre Meta ha pubblicato Muse Spark Open, un modello multimodale Mixture-of-Experts con 816 miliardi di parametri totali, 42 miliardi attivi per token e contesto fino a un milione di token. Accetta testo, immagini, audio e video. È progettato anche per il coding agentico e supporta llama.cpp, SGLang e vLLM. Sono già disponibili versioni GGUF, ma persino la quantizzazione Q2_K occupa circa 304 GB. I pesi sono pubblici con una licenza specifica, non una licenza open source riconosciuta dall'OSI. Perché conta: una novità importante per i modelli open-weight, ma non ancora utilizzabile su un normale desktop o Raspberry Pi.

Fonti: Presentazione tecnica · Versioni GGUF

2. Ubuntu 26.10: kernel 7.3, Rust e intelligenza artificiale locale

Il 15 ottobre Canonical ha rilasciato Ubuntu 26.10, nome in codice Stonking Stingray. Le novità principali sono GNOME 51, Mesa 26.2, strumenti di sistema cp, mv e rm scritti in Rust, immagini ottimizzate x86-64-v3 e prime immagini desktop RISC-V. Il kernel 7.3 incluso è ancora una release candidate. Arriva inoltre Myna, una funzione sperimentale di dettatura basata su modelli locali. Perché conta: vale la pena provarla in una VM per valutare kernel 7.3, prestazioni e riconoscimento vocale. Non è necessario modificare Linux Mint 22.3.

Fonti: Annuncio Canonical · Analisi OMG! Ubuntu

3. Forgejo 17.0: CI/CD self-hosted più completa

Il 15 ottobre è uscita Forgejo 17.0, la piattaforma Git libera che può essere ospitata su un proprio server. Le Forgejo Actions ora possono mostrare riepiloghi Markdown dei job, comprese tabelle e diagrammi Mermaid, utilizzando Runner 13.2 o superiore. Migliorano Git LFS, API dei workflow, completamento automatico delle issue e migrazione da Bitbucket Data Center. Perché conta: un'alternativa interessante a GitHub per NAS e server personali. Prima di aggiornare occorre controllare le modifiche incompatibili e i webhook deprecati.

Fonti: Annuncio ufficiale Forgejo

4. GitHub introduce AI Scan e Agentic Autofix

Dal 15 ottobre GitHub rende generalmente disponibili due strumenti di sicurezza. AI Scan esamina le pull request e cerca vulnerabilità anche in PHP, Bash, Dockerfile e Terraform, ampliando la copertura di CodeQL. Agentic Autofix permette a Copilot di esplorare il codice, correggere una vulnerabilità, rieseguire CodeQL e aprire una pull request con la soluzione proposta. Gli avvisi AI Scan non bloccano automaticamente i merge. Agentic Autofix richiede abilitazioni specifiche e consuma crediti AI e minuti GitHub Actions. Perché conta: interessante soprattutto per progetti PHP e workflow con agenti. Prima di attivarlo conviene controllare costi e risultati.

Fonti: AI Scan · Agentic Autofix

5. Linux Mint: migliorano il blocco della sessione e l'installer

Il 15 ottobre sono arrivati due interventi nei repository ufficiali di Linux Mint. In Cinnamon migliora il rilevamento del blocco della sessione tramite systemd-logind, anche quando si utilizza un salvaschermo esterno. L'installer live riordina le colonne delle partizioni, dando maggiore visibilità a punto di montaggio e formattazione, anche quando le etichette dei sistemi operativi sono molto lunghe. Perché conta: sono correzioni concrete nel codice di sviluppo, non aggiornamenti stabili già distribuiti. Nessun intervento necessario sul desktop Mint/MATE/Openbox.

Fonti: Commit Cinnamon · Commit installer

6. Libreboot 26.10 passa a UEFI aperto con EDK2

Libreboot ha rilasciato il 15 ottobre la versione 26.10, denominata Ominous Olive. La novità principale è l'adozione di EDK2 come payload UEFI predefinito su quasi tutte le schede supportate. Questo facilita l'avvio con systemd-boot, immagini kernel unificate, Linux, BSD e persino Windows su hardware compatibile. Il progetto ha inoltre importato i profili di 233 Chromebook supportati da MrChromebox. La compilazione riuscita non significa però che tutti siano stati collaudati fisicamente. Perché conta: un progresso importante per il firmware libero, specialmente sui vecchi computer. Non bisogna installarlo su hardware non esplicitamente supportato.

Fonti: Annuncio ufficiale Libreboot

7. Steam per Linux diventa a 64 bit nella nuova beta

La beta del client Steam pubblicata il 15 ottobre utilizza un eseguibile Linux a 64 bit, eseguito all'interno di Steam Runtime. L'obiettivo è rendere il client più uniforme fra distribuzioni. Attenzione: si tratta ancora della beta. Nelle discussioni tecniche alcuni utenti confermano che restano necessarie librerie e componenti a 32 bit. Perché conta: una modernizzazione attesa da anni. Da provare, ma senza rimuovere immediatamente tutte le dipendenze i386.

Fonti: Phoronix · Discussione degli utenti Linux

8. Strata 1.0: nuovo file manager Rust e GTK4

Strata è un gestore file orientato alla tastiera, progettato per Omarchy e Wayland. Offre tre modalità di navigazione: colonne Miller, icone e lista. Integra ricerca fuzzy, anteprime e isolamento tramite Bubblewrap per i parser più rischiosi. Richiede Linux a 64 bit, GTK 4.12 e glibc 2.39 o superiore. Perché conta: interessante da confrontare con Caja, Nemo e i file manager TUI. Consigliabile iniziare con un test non invasivo.

Fonti: Repository e schermate ufficiali · Presentazione Linuxiac

9. Claude Code aiuta a ricostruire un driver Linux per scanner

Christian Schaller, sviluppatore attivo nell'ecosistema GNOME, ha documentato un esperimento di reverse engineering assistito da AI. Utilizzando Claude Code, una macchina virtuale Windows e l'analisi del traffico USB, è riuscito a sviluppare un driver SANE funzionante per uno scanner di negativi e successivamente un'applicazione GNOME in Rust. Ha sperimentato l'agente anche nella diagnosi di problemi della webcam Intel IPU7 di un ThinkPad. Perché conta: un esempio concreto di come gli agenti possano aiutare a recuperare periferiche prive di driver Linux. Non significa che possano sviluppare autonomamente qualsiasi driver.

Fonti: Resoconto Phoronix

10. GitHub Copilot ritirerà tre modelli il 16 novembre

Il 15 ottobre GitHub ha annunciato che dal 16 novembre 2026 non saranno più disponibili in Copilot Claude Opus 5, Claude Opus 4.8 e GPT-5.6 Terra. Esiste un'eccezione per Opus 4.8 su alcuni abbonamenti individuali annuali. Le alternative indicate comprendono Opus 5.5 e modelli GPT-6. Perché conta: chi utilizza questi modelli nei workflow Copilot deve aggiornare le configurazioni. Il cambiamento non implica automaticamente il ritiro delle API degli stessi fornitori.
