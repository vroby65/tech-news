Tech News Daily

Recap tech — 2 ottobre 2026

Le ultime 24 ore sono state soprattutto una giornata Linux e sviluppo: Ubuntu 26.10 entra in beta, Rust 1.99 migliora nettamente l’interoperabilità con C, Qt Creator 21 porta ACP/MCP al centro dell’IDE e GitHub continua a trasformare VS Code in un ambiente per agenti. Sul fronte hardware, Raspberry Pi aumenta ancora i prezzi per effetto del costo della memoria; nell’open source, invece, arriva una brutta notizia per OpenRadioss.

1. Ubuntu 26.10 Beta: Linux 7.3, GNOME 51 e coreutils in Rust

Canonical ha pubblicato la beta di Ubuntu 26.10 “Stonking Stingray”, con uscita stabile prevista il 15 ottobre. Le immagini includono Linux 7.3-rc, GNOME 51, Mesa 26.2, GStreamer 1.30 e una toolchain molto recente con GCC 16, Python 3.14 e OpenJDK 27. Continua inoltre la transizione verso i coreutils scritti in Rust e migliora l’integrazione con autenticazione Microsoft, smart card e PKCS#11.

Perché conta: è una fotografia molto chiara della direzione che prenderà lo stack Ubuntu nei prossimi mesi. Da provare: sì in VM o live USB; non la userei ancora come sistema principale.

Fonte primaria: Ubuntu · OMG! Ubuntu

2. Rust 1.99: ora Rust può definire direttamente funzioni C variadiche

Rust 1.99 stabilizza la definizione di funzioni variadiche compatibili con ABI C e C-unwind. Rust poteva già chiamare funzioni come printf; ora può anche implementare direttamente API basate su .... Arrivano inoltre nuove API stabili per ricavare size e alignment da raw pointer e numerose aggiunte alla standard library.

Perché conta: riduce un’altra barriera nell’integrazione Rust/C, importante per kernel, librerie di sistema e FFI. Da provare: sì; con rustup basta il normale aggiornamento della toolchain stable.

Fonte primaria: Rust

3. Qt Creator 21 Beta: ACP e MCP diventano funzioni predefinite

Qt Creator 21 Beta abilita per default l’integrazione ACP e il server MCP. MCP richiede ora autenticazione con bearer token; ACP passa al protocollo v2 e la chat può aggiornare agenti, gestire sessioni per workspace, cambiare agente e mostrare consumo di token per sessione e singolo turno. Arrivano anche supporto Podman, HarmonyOS sperimentale e Windows remoto via SSH.

Perché conta: l’IDE Qt non tratta più gli agenti come plugin marginali: ACP e MCP entrano nel normale ambiente di sviluppo. Da provare: sì se si sviluppa in Qt/C++, ma resta una beta.

Fonte primaria: Qt

4. GitHub Copilot/VS Code: automazioni, HydraFusion e agent merge

GitHub ha riepilogato le novità agentiche arrivate in VS Code durante settembre. Tra le più interessanti ci sono HydraFusion, che sceglie automaticamente modelli e workflow, automazioni schedulabili, agent merge per gestire feedback di review, check falliti e conflitti, e la possibilità di creare pull request direttamente dalle sessioni Copilot, Claude o Codex. Gli agenti possono inoltre partire dentro Dev Container e le conversazioni Codex possono essere riprese tra ChatGPT e VS Code.

Perché conta: il coding agent sta passando da “chat che modifica file” a processo persistente che può seguire un lavoro fino al merge. Da approfondire: sì, soprattutto HydraFusion e agent merge; diverse funzioni sono ancora preview.

Fonte primaria: GitHub

5. AMD prepara un’altra ottimizzazione memoria per Linux 7.4

AMD ha messo in coda per Linux 7.4 un’ottimizzazione RMPOPT che riduce lavoro inutile nella gestione delle page table su piattaforme AMD. Arriva dopo altre ottimizzazioni recenti rivolte soprattutto alle iGPU e ai carichi AI/LLM.

Perché conta: Linux 7.4 si sta delineando come una release particolarmente ricca di miglioramenti AMD, alcuni dei quali incidono direttamente sui sistemi con grafica integrata e memoria condivisa. Da fare: nulla ora; è lavoro upstream da attendere nella release stabile.

Fonte: Phoronix

6. Raspberry Pi 5 2 GB sale a 77,50 dollari

Raspberry Pi ha aumentato di 12,50 dollari il prezzo delle varianti da 2 GB: Raspberry Pi 4 passa a 67,50 dollari e Raspberry Pi 5 a 77,50 dollari. Eben Upton attribuisce la decisione al forte aumento del costo della memoria. Restano invariati i modelli da 1 GB e i Compute Module 4/5 da 2 GB.

Perché conta: il Pi 5 da 2 GB perde una parte importante del vantaggio economico che tradizionalmente distingueva Raspberry Pi dai mini-PC. Da valutare: prima dell’acquisto confronterei ormai sempre il prezzo complessivo Pi + alimentatore + storage + case con un mini-PC usato o entry-level.

Fonte primaria: Raspberry Pi

7. Siemens chiude OpenRadioss: stop a un promettente progetto open source

Siemens ha deciso di interrompere OpenRadioss, versione open source del solver agli elementi finiti Radioss. Il progetto era nato in Altair e la situazione è cambiata dopo l’acquisizione di Altair da parte di Siemens.

Perché conta: è un promemoria concreto del rischio di dipendere da un progetto open source controllato quasi interamente da una singola azienda: una licenza aperta protegge il codice già pubblicato, ma non garantisce che lo sviluppo continui. Da seguire: sì, soprattutto per vedere se nascerà un fork comunitario.

Fonte: Phoronix

8. Nitrux 7.0: desktop Hyprland sempre più costruito in casa

Nitrux 7.0, distribuzione senza systemd, sostituisce diversi componenti esterni della sessione con un proprio Workspace Environment coordinato da nwsm e OpenRC. Hyprland rimane il compositor, ma Waybar, Crystal Dock, SwayNC, Hyprlock, Wlogout e Grimshot escono dalla configurazione predefinita a favore di componenti Nitrux.

Perché conta: è un esperimento interessante di desktop Wayland integrato senza systemd e senza costruire un compositor da zero. Da provare: sì in VM o macchina secondaria, soprattutto per chi segue ambienti Wayland alternativi.

Fonte: Linuxiac

Da tenere d’occhio

HydraFusion — il routing automatico fra modelli potrebbe diventare più importante della scelta manuale del “modello migliore”.

Linux 7.4 su AMD — continua ad accumulare ottimizzazioni interessanti per iGPU, memoria e workload AI locali.

OpenRadioss — da osservare se la comunità sfrutterà la natura open source del codice esistente per continuare il progetto con un fork indipendente.
